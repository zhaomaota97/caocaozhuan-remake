# 公共章节阶段：头像与成长共用字段

公共记录 `0x4B0770+6` 不应仅根据头像表现命名为“年龄”。已定位的 EEX 写入路径把它与章节标题关联，以下称为章节阶段，保留原始字节值。

## 两条写入路径

`opcode103 → 0x413B3D` 读取 tag4 的 32 位参数，再读取 tag5 字符串。它调用 `0x4179A5` 复制标题、`0x47FAD0` 做字节饱和减一、`0x418C70` 将结果写到公共记录 +6，最后调用标题显示函数 `0x40B940`。

实际状态值为 `max((value & 255)-1,0)`。注意减一前已经截为字节，并且首参数的低16位等于 0x8000 时直接返回 5，未读取标题、不修改阶段。成功返回 1。

标题复制器不是一般的 UTF-8 字符串复制：小于0x20的字节单独复制，其余按两字节复制；遇到字节序列 `0A 26`（换行后跟 `&`）提前终止。Web 解释器应基于已经解码的游戏文本语义处理，不要直接套浏览器字符串字节假设。

`opcode58 → 0x4149F7` 读取 tag40、tag52、tag4。当第一参数等于 1 时，将第三参数低字节直接写入公共记录 +6；该分支不使用第二参数的值。opcode58 其他分支还会修改其他公共属性，不在本次动态验证范围。

## 下游用途

- `0x4075A7`：身份0的头像在阶段<2和阶段>=2时使用不同起始索引，再叠加公共表情状态。
- `0x442890`：对内部编号大于0xAD的单位，阶段0令处理模式为0，阶段1令模式为1，阶段2/3令模式为2，影响后续等级/兵种相关调整。具体单位调整完整链仍需另行验证。
- 公共记录存取与剧情状态恢复必须保留这个字段，不能只在头像组件内存一份局部变量。
