# 存档分区差异摘要

复现：`python tools/compare_save_parts.py 08` 与 `python tools/compare_save_parts.py --stable`。

slot 8 的三个分区大小为：`Sv08s.e5s` 5,891 字节、`Sv08e.e5s` 10,330 字节、`Sv08d.e5s` 21,724 字节。`s` 分区的运行时战场结构从偏移 `0x23` 起包含 1266 字节状态、115×26 字节演武将记录和占用图；`d` 分区的普通对象表从 `0x14DC` 起包含 512×32 字节记录；`e` 分区是附加场景/事件数据，当前只作字节级差异保存。

跨 00-09 槽的稳定偏移比较显示：`s` 分区大部分差异集中在状态和演员/占用区域，`d` 分区绝大多数高偏移对象记录随存档变化，`e` 分区只有少量跨槽稳定字节与大范围变化区。该工具不把跨槽稳定性直接解释为“未使用字段”，因为不同槽可能来自不同剧情和战场。

原版加载入口 `0x41AD06` 只在读取头部后继续解释版本为 5 的分区；本轮动态文件钩子确认 slot8 D/S 头部读取成功，但尚未捕获确认后的完整 `d/e/s` 读取返回。机器差异输出仍由命令即时打印，原始分区文件保留在运行目录。
