# slot 8 分区头部观察

对运行目录中的 `SV08D.E5S`、`SV08S.E5S`、`SV08E.E5S` 做字节级观察：D/S 分区首字节均为版本 5，E 分区首字节为 0，不能把 E 分区当成同样的版本化主存档。D/S 前 16 字节和 `0x23` 附近字段已在本轮命令输出中核对；D 分区 `0x14DC` 处确实进入对象表，S 分区该处仍是填充区。

原版 `0x41AD06` 首先验证主存档缓冲区的首字节 5，然后读取 D/S 结构并进入附加文件逻辑。E 分区由另一条场景/事件路径处理，不能套用 S 分区的 1266+115×26 布局。slot8 的 E 分区大小 10,330 字节，作为独立事件数据保留，当前没有给其首字节 0 赋予“无效”语义。

这组观察与已有 codec 验证互补：codec 验证的是 D/S 记录往返；本报告明确标出 E 分区版本和结构仍需专门调用链验证。
