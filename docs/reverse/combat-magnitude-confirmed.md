# 战斗数值函数（`0x43BFAA`）

这是当前已验证的核心数值路径。参数 `param_3` 是效果/攻击类型，`param_4 == 0` 表示普通带随机扰动的计算路径。

## 计算顺序

1. 通过 `0x49BAC`/`0x49C36` 检查效果类型是否有效；不满足时返回 0。
2. 普通路径先检查 `0x3B4B0` 的免疫/限制条件。
3. 类型 `0x09` 和 `0x15` 直接取目标当前值（`0x72C90`）。
4. 其他类型从基础值 `attacker_stat + 0x19` 开始，并按类型选择倍率：

   * `7/10`：0、3、5、8、0x0B、0x0F、0x11、0x14、0x21、0x40
   * `9/10`：1、4、6、0x10、0x12
   * `5/10`：2、7、0x0A、0x0D、0x16、0x23
   * `4/10`：0x0C、0x22
   * `2/10`：0x0E、0x24
   * `12/10`：0x13、0x26
   * `10/10`：0x41

5. 双方对应属性差按每 3 点折算一次，攻击方较低时使用饱和减法。
6. 对目标效果类别 `0x27/0x2A/0x2B` 乘 `11/10`，`0x31/0x32` 乘 `13/10`。
7. 效果 `0x14` 且攻击者类别为 `0x0C` 时翻倍。
8. 效果表中的两个百分比修正字段分别在标志为 0 和 2 时增加伤害；目标的 `';'` 字段按百分比减伤。
9. 普通路径调用游戏 RNG，产生小范围扰动。
10. 结果至少为 1，并封顶到目标当前值；效果 `0x16` 使用 `0x72840`，其他效果使用 `0x72C90`。

已用原生调用结果验证：`analysis/native-combat-magnitude-validation.json`，包含命中、随机数、地形和最终数值路径。

该函数本身只计算幅度；状态施加、状态恢复、阶段衰减和死亡/撤退写回属于后续调用链，不能把本函数单独当作完整战斗状态机。
