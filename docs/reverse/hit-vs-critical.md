# 命中率与会心率的区分

`0x43B50D` 是 `0x4404BD` 普通攻击分支调用的命中/成功率辅助函数，不是会心判定。

它的行为：

* 读取攻击者和目标的能力值 `0x43F631`；
* 按双方能力差把基础概率分段计算为约 30、60、90 或 100；
* 使用游戏 RNG 做分段内扰动；
* 根据武将表中的 `'`、`5`、`7` 字段做百分比修正；
* 目标拥有标志 `0x08` 时直接返回 100；某些目标属性标记则直接返回 0。

会心率则来自另一条路径：`0x41C4E9` 判定物品被动，`0x4404BD` 对类别 `0x41` 成功时把会心概率写为 100。两者都可能出现在同一攻击动作中，但语义不同：前者决定攻击是否命中，后者决定命中结果是否为会心。
