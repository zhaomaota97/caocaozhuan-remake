# 逆向还原约束

1. 运行时逻辑必须来自原版静态伪代码、native 合成验证或动态观测证据。
2. 没有证据的行为不得自行设计成“看起来合理”的规则；只能标记为 `unverified`、禁用，或保留原始数据。
3. 原始数据到新项目数据的每个映射必须保留来源文件、偏移、函数地址或验证工具。
4. 动画 sheet 的 tile 数量不等于帧时序。只有恢复方向、帧序和时钟后才能播放循环动画。
5. 战斗、命中、伤害、会心、移动费用和存档必须优先复用已验证的原版逻辑；重制代码不能替换为猜测公式。
6. 新项目不得运行时访问原项目目录、原始 `.e5/.e5s/.eex` 或未转换的资源。
7. 每个未完成系统必须在文档中明确列出，不得用占位实现冒充最大还原度。
